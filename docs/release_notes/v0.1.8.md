## v0.1.8

### Changed
- **The update check asks both GitLab and GitHub** and offers whichever has the newer version. If both have the same
  version, the installer comes from GitLab, and GitHub is used if that download fails. A downloaded installer must
  be a real Windows program before it runs. F1 > Update shows where the release was found.

### Notes
- If you're on v0.1.5 or older, run the new `SCDA_Setup.exe` once in update mode. After that, updates install from
  F1 > Update.
- The installer is unsigned: SmartScreen > More info > Run anyway.
