## v0.1.12

### New
- **Add to Steam (#9).** F1 / L3+R3 > **Update** > **Add to Steam** adds the game to your Steam library as a
  non-Steam game, so you can start it from Steam and use the Steam overlay and Steam Input.
  - Exit Steam first (Steam > Exit). Steam only reads its shortcut list when it starts, so the button waits until
    Steam is closed.
  - Every Steam account on the PC gets the shortcut. Clicking again doesn't add a second copy.
  - Your old Steam shortcut list is kept as `shortcuts.vdf.bak` next to the original, just in case.

### Notes
- If you're on v0.1.5 or older, run the new `SCDA_Setup.exe` once in update mode. After that, updates install from
  F1 > Update.
- The installer is unsigned: SmartScreen > More info > Run anyway.
