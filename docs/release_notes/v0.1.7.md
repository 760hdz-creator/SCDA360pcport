## v0.1.7

### Fixed
- **Controller camera drift with `GamepadSensitivity` above 1 (#13).** A stick resting near the centre was scaled
  past the deadzone, so the camera could creep and the mouse stopped working while a controller was plugged in.
  A resting stick is now left alone. The default (1.0) was not affected.
- A rare crash risk in F1 > Update when an update download failed.

### Other
- `scda.log` now records the game's achievement unlock messages, the first step toward in-game achievements (#6).
- Checked that the v0.1.6 CPU fix leaves the menu movie playing at its normal speed.

### Notes
- Everything from v0.1.6 is included (lower CPU use, in-game updates, brightness/gamma, FPS overlay, monitor choice,
  key rebinding). If you're on v0.1.5 or older, run the new `SCDA_Setup.exe` once in update mode. After that,
  updates install from F1 > Update.
- The installer is unsigned: SmartScreen > More info > Run anyway.
