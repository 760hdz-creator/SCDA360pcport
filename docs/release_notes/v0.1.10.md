## v0.1.10

### Faster
- **The once-a-second stutter is gone.** About once a second the game held a frame for 50-67 ms while it threw
  away old geometry copies all at once. It now does that a little every frame. Measured at internal resolution
  Scale 3 on an RTX 4080 SUPER:

  | Level | fps before | fps now | frames of 40 ms or more |
  |---|---|---|---|
  | Okhotsk (second part) | 29.3 | 30.0 | 3.7% -> 0.1% |
  | New York (busiest area) | 29.5 | 30.0 | 3.8% -> 1.3% |
  | Kinshasa | 29.6 | 30.0 | 1.6% -> 0% |

### Notes
- The game is capped at 30 fps, as on the Xbox 360. Going above 30 fps needs a separate fps unlock (planned, #5).
- Image output is unchanged.
- If you're on v0.1.5 or older, run the new `SCDA_Setup.exe` once in update mode. After that, updates install from
  F1 > Update.
- The installer is unsigned: SmartScreen > More info > Run anyway.
