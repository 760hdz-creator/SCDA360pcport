## v0.1.15

### New
- **Dynamic shadows toggle (#16).** F1 > Graphics > Dynamic shadows (`[Display] DynamicShadows=0|1`, on by default).
  Off removes the shadows that characters and objects cast from lamps and the sun. The lights themselves and the
  level's baked shadows stay, and it saves some GPU time. The Low preset turns it off; Medium and up turn it on.

### Fixed
- **Saves past the first 100 (#24).** The game lists only 100 saves, and the recomp used to hand them over in an
  arbitrary order, so new saves could be missing from the list. Saves are now listed newest first, so your latest
  100 always show.

### Notes
- If you're on v0.1.5 or older, run the new `SCDA_Setup.exe` once in update mode. After that, updates install from
  F1 > Update.
- The installer is unsigned: SmartScreen > More info > Run anyway.
