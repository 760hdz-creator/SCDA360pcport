## v0.1.16

### Fixed
- **Crash at the end of Kinshasa (#31).** The recompiler translated some of the game's jump tables so that they
  read the whole 64-bit register, but the original code only checks the low 32 bits. Near the end of Kinshasa this
  sent the game to a bad address. All 529 jump tables in the game now behave as on the console, which may also fix
  other rare crashes.
- **Mouse acceleration (#29).** The mouse now turns the camera directly (`[Input] MouseMode=Direct`, the
  default). Movement is linear, with no dead zone and no stick acceleration. Screens where the view doesn't
  turn (briefings, lock picking and other stick minigames) fall back to the old stick mapping on their own.
  `MouseMode=Stick` brings back the old behaviour everywhere.
- **Save/load messages mention the Xbox 360 (#30).** The saving, loading and overwrite dialogs now say PC in all
  5 languages.

### Notes
- If you're on v0.1.5 or older, run the new `SCDA_Setup.exe` once in update mode. After that, updates install from
  F1 > Update.
- The installer is unsigned: SmartScreen > More info > Run anyway.
