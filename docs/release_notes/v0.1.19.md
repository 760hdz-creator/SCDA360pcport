## v0.1.19

### Fixed
- **Crash when loading some saves (#26).** v0.1.18 could crash to the desktop right after you loaded a save,
  for example in the Sea of Okhotsk or Kinshasa. Saves made in v0.1.16 were affected too. One part of the v0.1.18
  speed-up told the game that the GPU had finished with its data before the renderer had drawn it. The game then
  reused that data too early. This part is now off.
- **Flickering and wrong surfaces in busy scenes (#26).** The same early signal also caused flicker and broken
  frames when you turned the camera. A second cause was fixed too: when the shader constant buffer filled up and
  started over, one shader stage could read garbage values for a few draws.
- **Mouse wheel walk speed (#35)** now has 4 steps, like the PC version (it had 5).

### Performance
- Busy scenes are a little slower than in v0.1.18, because the game now waits for the renderer again before it
  reuses its data. The other v0.1.18 improvements stay.
- Measured on the #26 snow save (about 9,200 draws per frame) on a fast PC: 28.8 fps, with 8% of frames slow
  (v0.1.17: 28.2 fps, 22% slow; v0.1.18: 30 fps, but with the crash and flicker). Making each draw cheaper is the
  next step for #26.

### Notes
- The testing switch `SCDA_NO_EARLY_FENCES=1` is gone. `SCDA_EARLY_FENCES=1` turns the old v0.1.18 behaviour
  back on, for testing only.
- If you're on v0.1.5 or older, run the new `SCDA_Setup.exe` once in update mode. After that, updates install from
  F1 > Update.
- The installer is unsigned: SmartScreen > More info > Run anyway.
