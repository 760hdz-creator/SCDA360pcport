## v0.1.6

### Fixed
- **High CPU use (#4).** Three of the game's background loops kept a processor core busy at 100% even with nothing
  to do: the graphics wait in the main game thread, the loading-screen/movie thread, and a timer thread. On the Xbox
  360 these just used up spare hardware threads; on a PC they took cores away from everything else. They now sleep
  while they wait. Measured in Ellsworth Prison (Jail), per-thread CPU over 20 seconds: about 3.3 cores busy before,
  about 1.1 now, at the same 30 fps. Sea of Okhotsk and Kinshasa also finish loading 8-16 seconds sooner. This should
  help most on 4- and 6-core CPUs such as the FX-6300 in the report.
- **The update check looked at the old GitHub page.** It now asks GitLab, where releases are published.

### New
- **Install updates from the game (#7).** F1 > Update > "Install update now" downloads the new `SCDA_Setup.exe`,
  closes the game, swaps `scda.exe` and starts the game again. "Install updates automatically at startup" (or
  `[Update] AutoInstall=1`) does it without asking. Save before you use it: unsaved progress is lost.
- **Brightness and gamma (#21):** F1 > Display, or `[Display] Brightness=` / `Gamma=` (0.5-2.0, 1.0 = console).
- **Performance overlay (#23):** `[Display] PerformanceOverlay=FPS` or `Detailed` (frame time, CPU use, resolution).
- **Monitor choice (#12):** `[Display] Monitor=1` (0 = main display), or F1 > Display when you have more than one.
- **Keyboard and mouse rebinding (#1):** a `[Keys]` section in `settings.ini`, e.g. `A=Enter,Space` or `Walk=Shift`.
  See the README for all action and key names. The on-screen key icons still show the default keys.
- **Walk key (#1):** hold Shift (or your `Walk` key) to move at `[Input] WalkSpeed` (default 0.5) for slow, quiet
  movement on the keyboard.
- **Controller options (#13):** `[Input] Gamepad=0` ignores controllers; `GamepadSensitivity=` (0.25-3) changes how
  fast the controller turns the camera.

### Notes
- The game is still capped at 30 fps; unlocking it (#5) needs separate work on the game's timing.
- Updating from v0.1.5: run the new `SCDA_Setup.exe` once (update mode). After that, updates can be installed from
  inside the game.
- The installer is unsigned: SmartScreen > More info > Run anyway.
