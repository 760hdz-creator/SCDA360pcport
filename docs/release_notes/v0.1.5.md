## v0.1.5

### Fixed
- **Character shadows at JBA HQ (#6).** Sam, Moss, other characters and furniture now cast shadows from the HQ room
  lights again, as on the Xbox 360 (checked in the wooden room on the way to "Bug antenna on the roof"). The game's
  light mask was being cleared to "fully lit", which hid every dynamic shadow in those rooms.
- Kinshasa and the other levels keep their current lighting: the new clear is only used where the console's memory
  would hold shadow-map data at that moment.

### Notes
- This is an approximation of what the console's GPU memory holds. If a level shows lighting that looks wrong
  compared with the Xbox 360, please report it with a screenshot and `scda.log`.
- Install: run `SCDA_Setup.exe` (an existing install can use update mode: it only replaces `scda.exe`, keeping game
  data, settings and saves). The installer is unsigned: SmartScreen > More info > Run anyway.
