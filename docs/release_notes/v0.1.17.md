## v0.1.17

### Fixed
- **Sam's legs mirrored in the Okhotsk ice-hole water (#36).** The water reflection is drawn from a mirrored
  camera that should cut away everything below the surface. The port ignored that cut (a user clip plane), so the
  underwater half of Sam showed up upside down in the hole. Clip planes are now on again, which also cleans up the
  smear in the Iceland ice hole. `SCDA_NO_UCP=1` turns them off for testing.

### New
- **Mouse wheel sets walking speed (#35).** In game, each wheel notch changes how fast the movement keys move Sam
  (5 steps, wheel up = faster). This works like the PC version. Holding `Walk` (Shift) still slows him down on top
  of that. In menus the wheel scrolls as before. `[Input] WheelMoveSpeed=0` brings back the old behaviour, where
  the wheel works as d-pad up/down in game too.
  - Wheel up in game no longer turns on the goggles. Use the `Up` arrow key (d-pad up) instead.
  - Smooth-scrolling mice and touchpads now register wheel movement too.

### Notes
- If you're on v0.1.5 or older, run the new `SCDA_Setup.exe` once in update mode. After that, updates install from
  F1 > Update.
- The installer is unsigned: SmartScreen > More info > Run anyway.
