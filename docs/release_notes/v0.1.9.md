## v0.1.9

### Faster
- **Less stutter in the busiest areas.** In New York (newyork_02), the share of frames that take 40 ms or longer
  dropped from about 9% to about 4%. Average speed went from 29.2 to 29.5 fps, against the game's 30 fps limit.
  Measured at internal resolution Scale 3 on an RTX 4080 SUPER.
- **Less work per frame for the renderer and the GPU command thread.** Rendering New York's busiest view now
  takes 22.3 ms per frame instead of 25.1 ms, and the command thread does about 1 ms less work per frame. Most of
  the gain matters on slower CPUs, where these threads were closer to the limit.

### Fixed
- **The game now restarts after an in-game update (F1 > Update > Install now).** Since v0.1.6 the update itself
  installed, but the game did not reopen because the restart path was missing a `\`. This fix takes effect for
  updates installed from v0.1.9 on.

### Notes
- The game is capped at 30 fps, as on the Xbox 360. Going above 30 fps needs a separate fps unlock (planned, #5).
- Image output is unchanged. These changes skip repeated work only.
- If you're on v0.1.5 or older, run the new `SCDA_Setup.exe` once in update mode. After that, updates install from
  F1 > Update.
- The installer is unsigned: SmartScreen > More info > Run anyway.
