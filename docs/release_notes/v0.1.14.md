## v0.1.14

### Fixed
- **Extra Settings menu (F1 / L3+R3): options no longer overlap.** The Display tab had more rows than fit, so the
  last options were drawn under the footer. The menu is taller now, and tab contents scroll if they still don't fit
  (small windows).

### Changed
- **New Game tab.** Brightness, Gamma, Field of view, Clean goggles and Language moved there from Display.
  Anisotropic filtering moved to Graphics. Tabs: Display, Graphics, Game, Update, Achievements.

### Notes
- If you're on v0.1.5 or older, run the new `SCDA_Setup.exe` once in update mode. After that, updates install from
  F1 > Update.
- The installer is unsigned: SmartScreen > More info > Run anyway.
